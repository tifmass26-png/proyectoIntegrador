# Proyecto OasisSpa
## Épicas, Features e Historias de Usuario – Nivel 2

---

## ÉPICA 1 – RESERVAS DE SERVICIOS
**Objetivo:** Permitir que el cliente registre sus datos, seleccione un servicio y reserve una cita en OasisSpa.

### Feature 1.1 – Registro de datos del cliente
* **HU 1.1.1:** Como cliente, quiero ingresar mi nombre completo y número de identificación, para registrar mis datos al momento de realizar una reserva.
* **HU 1.1.2:** Como cliente, quiero aceptar los términos y condiciones, para poder continuar con mi reserva.
* **HU 1.1.3:** Como cliente, quiero ingresar un código Captcha, para verificar que soy una persona y continuar con la reserva.

### Feature 1.2 – Selección de la reserva
* **HU 1.2.1:** Como cliente, quiero seleccionar el tipo de servicio que deseo, para reservar el tratamiento que necesito.
* **HU 1.2.2:** Como cliente, quiero seleccionar el día, fecha y hora de mi cita, para reservar un horario disponible.

### Feature 1.3 – Validación de la reserva
* **HU 1.3.1:** Como cliente, quiero que el sistema valide mis datos y la disponibilidad de la cita, para evitar errores al realizar mi reserva.

### Feature 1.4 – Confirmación de la reserva
* **HU 1.4.1:** Como cliente, quiero recibir la confirmación de mi reserva, para saber que mi cita quedó registrada correctamente.

---

## ÉPICA 2 – MÉTODOS DE PAGO
**Objetivo:** Permitir que el cliente seleccione un método de pago y realice el pago correspondiente para confirmar su reserva.

### Feature 2.1 – Selección del método de pago
* **HU 2.1.1:** Como cliente, quiero seleccionar mi método de pago entre efectivo, transferencia, crédito o débito, para elegir la forma de pago que prefiero.

### Feature 2.2 – Pago de la reserva
* **HU 2.2.1:** Como cliente, quiero realizar el pago del 50% del valor del servicio, para confirmar mi reserva.
* **HU 2.2.2:** Como cliente, quiero conocer el valor que queda pendiente después del anticipo, para saber cuánto debo pagar posteriormente.

### Feature 2.3 – Código de descuento
* **HU 2.3.1:** Como cliente, quiero ingresar un código de descuento, para obtener el beneficio correspondiente en el valor de mi reserva.

### Feature 2.4 – Confirmación del pago
* **HU 2.4.1:** Como cliente, quiero recibir la confirmación de mi pago, para verificar que el sistema registró correctamente la transacción.

### Feature 2.5 – Cancelación y reprogramación de la cita
* **HU 2.5.1:** Como cliente, quiero solicitar la reprogramación de mi cita con al menos 24 horas de anticipación, para poder cambiar la fecha o el horario de mi reserva.
* **HU 2.5.2:** Como cliente, quiero conocer las condiciones de cancelación y devolución, para saber qué sucede con mi anticipo si cancelo la cita.
* **HU 2.5.3:** Como cliente, quiero conocer el valor que puedo recibir en caso de cancelación, para saber si tengo derecho a devolución del 50% del anticipo según las condiciones establecidas.
